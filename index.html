Technical problem solving

My troubleshooting method

I solve problems one step at a time.

When a network cannot connect, a serial port is missing or an application does not start, I begin with the simplest checks. I collect information, test each possible cause and confirm that the final solution works.

diagnostic.log
$ ping 10.2.2.2
Reply received — path reachable
$ tracert 10.2.2.2
Checking the route one hop at a time...
$ verify configuration
✓ Cause of the problem found

  1. Define the symptom

    Record what failed, what still works, when it started and how to reproduce it.

  2. Check the foundations

    Verify power, cabling, interfaces, addressing and configuration before changing anything.

  3. Isolate the layer

    Move through physical, data-link, network and application layers using focused tests.

  4. Test one hypothesis

    Change one variable, compare the result and avoid introducing a second unknown.

  5. Verify and document

    Confirm the full service, record the solution and note how to prevent recurrence.
